From provisioning Linux virtual machines to deploying websites, we are exploring how cloud infrastructure, networking, security and Linux administration work together across Amazon Web Services and Microsoft Azure.

Our Project Objective

One Website. Two Cloud Platforms.

Our goal is to deploy the same custom website on two different cloud platforms using Ubuntu Linux virtual machines.

We are following a practical, step-by-step approach: provision cloud infrastructure, configure secure connectivity, administer Linux, install a web server, deploy our website and verify application accessibility.

This project helps us understand the similarities and differences between AWS EC2 and Microsoft Azure Virtual Machines through actual hands-on implementation.
